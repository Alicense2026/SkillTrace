# Third-party data notice

This dataset contains metadata gathered from Hugging Face and GitHub on 20 and 22 October 2026.

Repository and model identifiers, descriptions, public URLs, and license texts remain associated
with their original authors and platforms. The package does not claim ownership of those materials.

The GitHub license evidence archive contains repository-level license files collected solely for
license analysis and provenance. Users redistributing these files should review the corresponding
upstream license and platform terms.

Original records may include URLs, descriptions, and license identifiers. No private repositories
or authentication tokens are intentionally included.
