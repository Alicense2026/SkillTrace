# 许可证组合统计说明

输入为本目录 `result.csv`，共 23,206 条数据。忽略仓库名，按 GitHub 许可证、资产许可证原文标题/标签、调用方式（代码修改）分组，按数量降序输出 UTF-8 BOM CSV。

- 输出：413 组，合计 23,112 条关系。
- 按用户实验口径排除 GPL-2.0 系列 65 条、LGPL 系列 29 条，共 94 条。
- Gemma 主许可按 Apache-2.0 合并（3 条）；ODC-BY 统一为 ODC-BY-1.0（2 条）；BUSL-1.1 保留（99 条），后续按模板分析，不要求额外许可参数。
- 许可证标签大小写统一；直接标注的 Llama 许可证沿用原标签。proprietary 按资产 URL 匹配协议标题，Llama 再按资产名匹配版本，37 条版本无法识别的记录按约定采用 Llama 4。
- Cohere 使用 API 适用的 Commercial SaaS Agreement；百度使用本地文件的用户服务协议标题，该文件还包含线上订购协议。
- unknown、other、Unlicense 与自定义标签仍保留在统计中。表格不代表冲突检测或合规判定结果。
