# ASC 缺口补提取与防丢失修复

输入沿用 `paper/evaluation/skill-supply-chain-2026-11-13/filtered-no-unlicense/retained_relationships.csv`。原实验 147/148 分段通过格式校验，1,711 条 ASC；尚有 258 个段落自报未解决。本轮冻结原实验的清单、语料和已验证输出，写入 baseline/，不覆盖原始实验。

## 本轮政策

1. 跨段缺口：以完整带行号原文提供上下文，仅向目标段落补充条款，可记录其他条款的 supporting_source_ranges。
2. 活动词表固定：优先将附属义务放入现有行为的条件与 obligation_items；不能忠实表达的内容记为 OUTSIDE_ACTIVITY_SCOPE，不创建活动或伪造 Use/UNSPECIFIED 条款。
3. 外部文件：原文确实没有提供的外部引用记为 EXTERNAL_REFERENCE_EXCLUDED，不下载、不推断其内容、不因此判定许可或合规。同份文件中的其他章节不属于外部文件。混合段落仍提取本地可表达部分。
4. 丢失修复：保留所有基线规则；补丁仅增量添加；历史原始输出中的候选须核验后恢复。Mistral 的格式校验退化已单独检查。历史条款数量下降只代表疑似回退，可能也有去重/纠错，不能简单把所有旧条款重新相加。

## 文件

- scripts/repair_segmented_asc_gaps.py：准备冻结基线、构造缺口请求、并发执行、校验增量补丁、汇总新语料。
- scripts/extract_segmented_asc.py：原分段提取器；新增 retain_valid_clauses，格式/覆盖修复不得无说明删除先前结构有效条款。
- tests/test_asc_gap_repair.py：活动扩展拒绝、外部排除保留、恢复条款必需核验、跨段引用校验、条款防丢失及标签冲突测试。
- plan.json：本轮目标段落、原有条款数量、恢复来源。
- requests/、responses/、errors/：每次请求、原始响应和错误，无 API 密钥。
- superseded/：提示词或校验修复前的补丁，保留供追踪。
- validated/：当前通过校验的增量补丁。
- structured_asc.json、licenses/：原有规则与新增/恢复规则合并后的语料。
- gap_ledger.json：逐段处置与原因。
- recovered_anchor_review.json：Mistral 恢复候选的模型语义核验。
- historical_regression_scan.json：全分段历史响应扫描发现的条款数下降线索。
- summary.json、补提取结果.md：随运行更新的汇总，未结束时仅为中间结果。

运行：`python3 scripts/repair_segmented_asc_gaps.py --execute --workers 6`。模型及密钥从既有配置读取。无 --execute 时只检查、汇总已有输出。单进程文件锁防止重复启动；每个分段最多尝试三次，失败保存原因并继续其他分段。

没有把机器格式校验、段落审计或模型自检当作独立专家覆盖率。排除项不计为已建模约束；最终仍需保留真实的未解决缺口。

## 最终复核与交付

`python3 scripts/repair_segmented_asc_gaps.py --review-history --execute --workers 4` 对历史数量下降候选逐条核验；`python3 scripts/audit_asc_gap_repair.py` 验证并生成最终报告。

- scripts/review_asc_regressions.py：历史候选核验，使用短引用编号避免模型抄错长 rule_id，精确相等候选直接记为已有覆盖，新增无效候选隔离且保留原因；基线规则不删除。
- scripts/audit_asc_gap_repair.py：核对源文件哈希、精确摘录、规则 ID、固定词表及基线保留，生成最终核验记录和报告。
- reviewed_structured_asc.json、reviewed_licenses/：最终核验后的完整语料，应优先于中间 structured_asc.json 使用。
- 最终补提取报告.md、final_verification.json：最终结果和一致性校验。
- representation_normalizations.json：带禁止条件的 PROHIBITED→CONDITIONALLY_PROHIBITED 表示归一化，不改变谓词内容，也不冒充模型原始返回。

原提取器与本轮补丁都加入防丢失保护。本轮后续补提取只处理仍未解决的目标，并把已通过的补丁条款设为不可删除锚点。范围外额外输出及明确排除的占位记录单独保留，不作为有效 ASC 计数。20 项相关测试通过。
