# 新供应链实验运行说明

输入：filtered-no-unlicense/retained_relationships.csv，共 6,113 条关系。原文、仓库和平台映射沿用 ASC 提取阶段的冻结 inventory.json；ASC 使用 skill-asc-gap-repair-2026-11-14/reviewed_structured_asc.json（1,923 条）。不使用旧版语料或旧实验冲突结果，不调用离线冲突引擎。

逐行由 GPT-6-luna 输出许可证—许可证比较、许可证—行为比较、两侧义务集合。每次包含完整 Figure 10 的 12 个案例及已有正反冲突模式。精确相同的原文摘录共享存储，所有 ASC 条款保留；未出现的业务事实为未知，不推断为假。

每条 ASC 必须有 rule_obligation_audit，说明纳入哪些义务（零基索引）或不纳入的原因。审计仅为模型自检，不代表专家覆盖率。义务状态 UNKNOWN 不等于违规；合规性结论以已检查对象、事实与条款为边界。外部引用文件缺失沿用上一轮排除政策。

creatorrrr/common-skills 的两条关系映射原文只有 UNLICENSED，无有效 ASC，记录 SKIPPED_MISSING_ASC。其三个输出槽位保留 output:null 与原因，不能记为无冲突。

- requests/：每行完整任务与请求哈希。
- attempt_requests/、responses/、errors/：每次实际请求、原始响应和错误，不写入 API 密钥。
- results/：经校验的九字段输出或失败/跳过原因。
- three_outputs/license_license/、license_activity/、obligations/：逐行三类输出。
- summary.json、实验结果报告.md：自动更新计数和最多三个冲突案例。区分关系数与发现条目数，失败和未运行不算合规。
- execution_state.json、launcher.json、worker.log：进程、后台启动与执行日志。
- milestones/：每处理 1,000 条保存统计快照。
- code_snapshots/：实际运行脚本的哈希版本。

继续全量：`python3 scripts/run_skill_asc_experiment.py --execute --workers 6 --background`

结果逐条原子写入，最多三次请求/格式修复，失败后记录并继续。恢复时只复用相同请求哈希且重新通过校验的结果；原始响应能够经精确格式归一化通过校验时直接恢复，避免重发。已有结果缺失三类分文件时自动重建。

脚本的字符保护上限为 600,000（原接口 180,000 不足以容纳部分完整许可对）；普通样本最多 24,000 输出 token，超过 150 条 ASC 的样本最多 48,000。上限不是实际用量；不截断条款、示例或响应。正式全量前执行普通与最大输入样本验证。
